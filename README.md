# 🚀 Advanced E-commerce Platform

[![Build Status](https://img.shields.io/badge/Build-Passing-brightgreen)](https://github.com/ahmedGHtarek0/Advanced-E-commerce-with-Advanced-Topics)
[![License: ISC](https://img.shields.io/badge/License-ISC-blue.svg)](https://opensource.org/licenses/ISC)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript-blue)](https://www.typescriptlang.org/)

A robust, high-performance E-commerce backend built with **Node.js**, **TypeScript**, and **MongoDB**. This project implements advanced features such as JWT-based authentication, multi-factor security (OTP), complex filtering, and automated email services.

![Project Preview](./assets/standard_preview.png)

---

## 🌟 Key Features

-   **🔐 Advanced Authentication**: Secure login and registration using JWT (JSON Web Tokens).
-   **🛡️ Multi-Factor Security**: OTP (One-Time Password) integration via Nodemailer for account verification.
-   **🛒 Cart Management**: Fully functional shopping cart system with persistent storage.
-   **📦 Product Catalog**: Comprehensive product management with advanced filtering and search capabilities.
-   **📧 Automated Emailing**: Integration with Nodemailer for order confirmations and security alerts.
-   **📁 File Handling**: Secure image uploading for products using Multer.
-   **🏗️ Clean Architecture**: Modular design following industry best practices for scalability.

---

## 🛠️ Tech Stack

-   **Runtime**: [Node.js](https://nodejs.org/)
-   **Framework**: [Express.js](https://expressjs.com/)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Database**: [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
-   **Authentication**: [JWT](https://jwt.io/)
-   **Email Service**: [Nodemailer](https://nodemailer.com/)
-   **File Storage**: [Multer](https://github.com/expressjs/multer)

## 🚀 Getting Started

### Prerequisites

-   Node.js (v18 or higher)
-   MongoDB instance (Local or Atlas)
-   npm or yarn

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ahmedGHtarek0/Advanced-E-commerce-with-Advanced-Topics.git
    cd Advanced-E-commerce-with-Advanced-Topics
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Environment Variables**:
    Create a `.env` file in the root directory and add your configurations (refer to the Advanced Documentation for details).

4.  **Run in Development Mode**:
    ```bash
    npm run dev
    ```
